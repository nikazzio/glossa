# Scorciatoie da tastiera

Le scorciatoie globali usano `Ctrl` su Windows e Linux. Su macOS puoi usare
`Cmd`. Salvo `Ctrl + Invio`, non vengono intercettate mentre il focus è in
un campo di testo, una selezione o un editor modificabile.

| Scorciatoia | Azione | Condizioni |
| --- | --- | --- |
| `Ctrl + Invio` | Avvia l’azione di traduzione selezionata | In modalità frammento richiede un frammento selezionato; funziona anche nei campi di testo |
| `Ctrl + S` | Salva il progetto e le risorse linguistiche modificate | Richiede un progetto esistente; il progetto non viene salvato mentre è in elaborazione |
| `Ctrl + E` | Apre l’esportazione | Richiede almeno un frammento |
| `Ctrl + ,` | Apre la configurazione della pipeline | Fuori dai campi modificabili |
| `Ctrl + H` | Apre questa sezione della guida in-app | Fuori dai campi modificabili |
| `Ctrl + 1` … `Ctrl + 9` | Seleziona uno dei primi nove frammenti | Il frammento deve esistere |
| `Esc` | Chiude la finestra o il menu attivo | Secondo il controllo aperto |

Se il progetto è in elaborazione, il comando di salvataggio segnala che il
salvataggio del progetto è rimandato; le risorse linguistiche modificate
possono comunque essere salvate. Non è un comando per assegnare un nome a
una bozza priva di progetto.

## Navigazione nei controlli

Usa `Tab` per raggiungere i controlli e `Invio` o `Spazio` per attivarli.
Le barre di schede supportano frecce e tasti `Home` e `End`. I suggerimenti
dei comandi a icona ne descrivono funzione e, quando pertinente, motivo
dell’indisponibilità.

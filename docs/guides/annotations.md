# Annotazioni

Le annotazioni ti permettono di allegare note ai chunk tradotti, così il feedback
di review resta vicino al testo a cui si riferisce.

## Tipi di annotazione

- Comment
- Doubt
- Problem
- Approved

## A cosa servono

- Segnare formulazioni irrisolte
- Conservare decisioni editoriali
- Preservare issue dell'audit che richiedono follow-up manuale
- Ancorare un commento a una frase precisa invece che al chunk intero

## Workflow tipico

1. Seleziona testo nella vista traduzione.
2. Crea un'annotazione ancorata a quella selezione.
3. Rivedi la nota nel chunk inspector o nel pannello note.
4. Converti le issue dell'audit in annotazioni quando vuoi conservarne il contesto.

## Regole pratiche

- Le note sorgente estratte dal documento restano separate dalle annotazioni utente.
- L'ancoraggio conta: la nota deve puntare all'occorrenza esatta che hai rivisto.
- Usa **Problem** per blocchi reali e **Doubt** per dubbi interpretativi.
- Usa **Approved** con parsimonia, quando il chunk è davvero chiuso.
- Preferisci note brevi e fattuali a discussioni lunghe dentro il chunk.

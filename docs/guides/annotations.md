# Annotations

Annotations let you attach notes to translated chunks so review feedback stays
close to the text it refers to.

## Annotation types

- Comment
- Doubt
- Problem
- Approved

## Common workflow

1. Select text in the translation view.
2. Create an annotation anchored to that selection.
3. Review the note in the chunk inspector or notes panel.
4. Convert audit findings into annotations when you want to keep the feedback.

## What to remember

- The source notes extracted from the document remain separate from user annotations.
- Anchoring matters: the note should point to the exact occurrence you reviewed.
- The visual treatment can change, but the underlying note data should stay stable.

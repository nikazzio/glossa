# Versioni e note di rilascio

Le modifiche pubblicate sono registrate nel
[changelog del repository](https://github.com/nikazzio/glossa/blob/main/CHANGELOG.md),
aggiornato dal processo di rilascio con `release-please`. La pagina delle
[release GitHub](https://github.com/nikazzio/glossa/releases) contiene note
e pacchetti associati a ciascuna versione.

## Quale riferimento consultare

- Per installare o aggiornare Glossa, leggi le note della release scelta e
  seleziona il pacchetto del tuo sistema.
- Per conoscere il comportamento documentato su `main`, consulta le guide
  di questo sito.
- Per distinguere funzioni disponibili e incomplete, consulta lo
  [stato del progetto](./status).

Documentazione e pacchetti hanno cicli di pubblicazione distinti. Una funzione
descritta sul sito può non essere ancora inclusa nell’ultima release scaricabile.

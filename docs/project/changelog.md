# Changelog

Il changelog ufficiale di Glossa si trova nel file `CHANGELOG.md` nella radice
del repository ed è mantenuto automaticamente da `release-please`.

- Ultime voci del changelog: [CHANGELOG.md](https://github.com/nikazzio/glossa/blob/main/CHANGELOG.md)
- Release su GitHub: [Releases](https://github.com/nikazzio/glossa/releases)

Quando il progetto pubblica una nuova release, il changelog e la Release
GitHub restano sincronizzati.

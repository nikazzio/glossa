## Using this documentation

Start with [Installation and first project](./intro/getting-started), then
read [Workspaces and projects](./guides/projects-and-workspace) for data scope.
For digital material, follow [Source search](./guides/source-search) and
[Library and IIIF viewer](./guides/library-discovery). For text work, see
[Translating a document](./guides/document-pipeline) and
[Assessment and review](./guides/audit-review).

Reference pages describe parameters, formats and integration limits. The
guide built into the application provides operational instructions for users.

## Documented version

This site follows `main`. Glossa is in private beta, and your installed
release may predate features described here. See [Project status](./project/status)
and [Versions and release notes](./project/changelog).
